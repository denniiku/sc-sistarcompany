# *SC WEB — PHASE 2 VISUAL UPGRADE SKILL (upgrade_skill.md)

## 1. CORE OBJECTIVE
Transform text-only editorial `*sc web` pages into visually rich, executive-grade interactive experiences using **100% code-native vector graphics (Inline SVG) and CSS infographics**—guaranteeing zero broken image links (`0%` external file dependency) and infinite Retina sharpness on the signature `*sc` pastel gradient background.

---

## 2. CODE-NATIVE VISUAL COMPONENTS LIBRARY

### A. Inline SVG Architecture & Ecosystem Diagrams
- **Use Case:** System architectures, platform integrations, hub-and-spoke ecosystems, and multi-entity networks.
- **Specification:**
  - Pure `<svg viewBox="0 0 900 320">` with responsive scaling (`width: 100%; height: auto;`).
  - Color Palette: Deep Slate (`#0f172a`, `#1e293b`), Emerald Accent (`#168765`), Soft Glass Fill (`rgba(255,255,255,0.45)`), Hairline Connectors (`stroke="#168765" stroke-dasharray="4 4"`).

### B. Horizontal Process & Lifecycle Flowcharts (SVG / CSS Stepper)
- **Use Case:** 3-to-6 stage pipelines, customer lifecycles, implementation roadmaps, and supply-chain flows.
- **Specification:**
  - Connected vector nodes with directional arrows, stage badges (`01` .. `06`), and milestone labels.

### C. Executive KPI & Data Infographic Cards
- **Use Case:** Performance metrics, ROI comparisons, market reach, and operational benchmarks.
- **Specification:**
  - Large Space Grotesk metric callouts (`2.8rem`), comparative CSS progress bars, and radial SVG gauge rings.

### D. Comparison & Strategy Matrices
- **Use Case:** Inbound vs. Outbound, Traditional vs. AI-Driven, or Multi-Tier product portfolios.
- **Specification:**
  - Clean architectural comparison tables and side-by-side vector visual contrast blocks without muddy background wrappers.

---

## 3. EXECUTION PROTOCOL
1. Read target `<page>/index.html` text sections.
2. Identify 3 to 5 key conceptual blocks per page (e.g., Hero Architecture, Process Flow, Ecosystem Map, KPI Impact).
3. Inject bespoke, context-matched Inline SVG diagrams and CSS infographics directly into those sections while preserving strict flush-left typographic alignment.
4. Run `sync_all.ps1` to deploy across all 12 GitHub repositories.

---

## 4. SPACIOUS 1-COLUMN CARD STACK STANDARD (NO CRAMPED MULTI-COLUMN TEXT BOXES)
- When presenting dense text blocks inside dark/emerald visual containers (such as Track I / Track II summaries or the 01–06 Core Domain Engine blocks):
  - **1 Box Per Row:** Use a full-width 1-column vertical flex/grid stack (`display: flex; flex-direction: column; gap: 16px;`) rather than cramming 2 or 3 boxes horizontally into a small fixed-width SVG.
  - **1 Paragraph/Item Per Line:** Place each numbered project or bullet point on its own dedicated line with comfortable font sizing (`1.02rem` body, `1.26rem–1.32rem` headings) so text is immediately legible without zooming.
