## 3. Dual-Page Factory Architecture (1 Project/Issue ➔ 2 Web Pages)

For every new project, business issue, or initiative, the system takes **5 Standard Inputs**:
1. **Memo:** Raw ideas, concepts, or strategic notes.
2. **Target `*sc` URL / Position:** Exact menu route & folder location in the 3-level navigator.
3. **Reference URL:** External benchmark webpages or industry articles.
4. **Files:** Local documents, PDFs, CSVs, or PPTX files.
5. **Google Drive URL:** Internal Drive documents, sheets, or folders.

Using `[Inputs] + [master_prd.md] + [master_skill.md]`, the factory produces **2 Web Pages simultaneously**:

### Track 1 — Page 1: Original Vision & Visual Creation (Gamma API / PPTX Track)
1. Synthesizes `[Memo] + [Drive/Files] + [master_prd.md]` via Gemini LM into a structured narrative.
2. Sends the structured prompt to **Gamma API (or Gamma PPTX workflow)** to polish copy and generate custom visuals.
3. Downloads the `.pptx` file, automatically extracts all high-resolution images into `./storage/`, and converts the slide text into a clean, box-free `index.html` adhering strictly to `master_skill.md`.

### Track 2 — Page 2: Reference Reverse-Engineering & Assetization (Benchmark Track)
1. Crawls the provided `Reference URL` (or searches for top-performing reference webpages on the topic).
2. Reverse-engineers the structure, key data points, and visual assets, saving images to `./storage/`.
3. Rewrites and internalizes the content through the lens of `master_prd.md` (`*sc` terminology and philosophy) and outputs a second clean `index.html` adhering to `master_skill.md`.
